# dev

Your test setup lives here.

Save your Reaper test project as `ShortwaveTest.rpp` in this folder, with its
audio files next to it. Visual Studio opens it automatically when you press F5
(see `docs/SETUP-WINDOWS.md`, step 5).

Good test material for a radio effect: a dry voice recording, a drum loop, and
a full mix. Keep files short so the repo stays small.
